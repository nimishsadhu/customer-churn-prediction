# Customer Churn Prediction

This project focuses on predicting whether a customer is likely to churn using machine learning.

I built this project to understand and implement the complete machine learning workflow, starting from understanding the dataset and preprocessing it to exploratory data analysis, feature engineering, model training, evaluation and final model selection.

## Project Workflow

The project follows these steps:

1. Data Inspection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Hyperparameter Tuning
8. Threshold Tuning
9. Final Model Extraction

## Dataset

The dataset contains information about customers and their services along with their churn status.

Some of the important features include:

- Tenure Months
- Monthly Charges
- Total Charges
- Contract
- Internet Service
- Payment Method
- Customer Status
- Location related features

The target variable used for prediction is `Churn Value`.

```text
0 → Customer did not churn
1 → Customer churned
